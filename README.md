# CLAVE CONSTRUCCIÓN — Sistema Digital de Inspección Técnica

Aplicación web interactiva para el levantamiento digital en campo y generación de informes técnicos de inspección de inmuebles de **CLAVE CONSTRUCCIÓN**.

## Paquetes de Servicio Soportados

1. **Esencial**
   - Revisión estructural visible (muros, losa, columnas)
   - Instalación eléctrica e hidráulica aparente
   - Acabados arquitectónicos (pisos, paredes y techos)
   - Equipamiento fijo (puertas, ventanas, cerrajería)
   - Informe escrito con registro fotográfico
2. **Integral** *(Más popular)*
   - Todo lo incluido en el paquete **Esencial**
   - Registro aéreo con dron
   - Revisión de humedad, filtraciones y áreas de difícil acceso
3. **Premium**
   - Todo lo incluido en el paquete **Integral**
   - Tour virtual 360°
   - **Respaldo Legal:** Dictamen técnico firmado por ingeniero o arquitecto colegiado

## Características Principales

- **Inspección por Área / Habitación (Opción B):** Evalúa cada espacio de forma ordenada, agregando, duplicando o personalizando habitaciones dinámicamente.
- **Evidencia Fotográfica Integrada:** Captura desde la cámara del celular/tablet o sube fotografías con compresión automática.
- **Firmas Digitales en Pantalla:** Pizarra táctil para firma del Inspector/Perito Colegiado y firma de conformidad del Cliente.
- **Guardado Automático y Respaldos:** Almacenamiento local automático (`localStorage`), historial de múltiples visitas y exportación/importación en archivo `.json`.
- **Informe Oficial Listo para PDF:** Generación instantánea del reporte membretado listo para imprimir o guardar como PDF.
